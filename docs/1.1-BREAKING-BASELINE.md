# Agent 1.1 Breaking Baseline

The complete Agent runtime package family and `Sunder.Package.Agent.Contracts` ship as `1.1.0`. This is a deliberate clean break from the unused 1.0 release. No compatibility shims are retained.

The breaking inventory includes the contract namespace/source reorganization, SDK logging replacement of Agent-specific provider logging types, async workspace migration contributors, ranged file operations with stable error codes and optimistic content hashes, payload bounds, role-separated App/Runtime gateways, typed Runtime operations/streams, host-owned callbacks, and forward-only checked SQLite migrations.

`PublicAPI.Shipped.txt` is the immutable 1.1 Contracts baseline; `PublicAPI.Unshipped.txt` is empty at the release boundary. Extension package runtime dependencies are `>=1.1.0 <1.2.0`. `packages.json` is the sole package/release/capability inventory and records exact generated capability manifests.

All 15 runtime archives must pass archive validation and a clean Runtime install/activation, graph unload/reload, and same-version reinstall smoke. At least the base Agent App snapshot must be produced, transferred, and accepted by the App snapshot activation gate.

Local execution is trusted host-user execution, not a sandbox: commands execute with the current host user's authority. Use the Docker target when operating-system isolation is required.
