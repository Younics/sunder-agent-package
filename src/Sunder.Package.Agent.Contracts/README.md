# Sunder Package Agent Contracts

Public extension contracts for the `sunder.package.agent` runtime package and its provider, tool, execution, memory, skill, and subagent extensions.

Use a Contracts version in the same 1.1 minor line as the installed Agent family:

```xml
<PackageReference Include="Sunder.Package.Agent.Contracts" Version="[1.1.0,1.2.0)" />
```

Runtime extension packages must also declare `sunder.package.agent` with `>=1.1.0 <1.2.0` in their Sunder package metadata.
